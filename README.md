# 보장비교 v1

보험료가 아닌 **약관상 보장 구조**를 비교하기 위한 정적 웹앱입니다. 실제 상담용 확정 데이터가 아닌 샘플 데이터로 동작하며, 모든 비교 결과는 약관 원문으로 재검증해야 합니다.

## 포함 범위

- 암: 진단비, 주요치료비(수술·항암약물·방사선 등 치료별 지급 규칙)
- 뇌: 진단비, 순환계/2대 주요치료비를 위한 입력 구조
- 심장: 진단비, 순환계/2대 주요치료비를 위한 입력 구조
- 수술: N대 질병수술비, 1~5종 수술비를 위한 입력 구조
- 간병: 간병인사용일당 입력 구조

현재 암 주요치료비 비교에는 대화에서 정리된 롯데·삼성·현대의 **샘플 값**이 들어 있습니다. 이는 상품 추천이나 최신 약관 판정이 아니며, 실제 사용 전 원문 약관, 조항, 기준일을 확인해야 합니다.

## 실행

별도의 설치가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

로컬 웹서버가 필요하면 VS Code의 Live Server 같은 정적 서버 확장을 사용해도 됩니다.

## 약관 데이터 추가 방식

`app.js`의 `sampleData`에 보험사별 상품 데이터를 추가합니다. 각 담보에 공통으로 아래 정보를 남깁니다.

- 보험사, 상품명, 상품버전, 판매상태, 담보명, 담보분류
- 가입금액, 갱신여부, 약관기준일, 약관근거, 약관 원문, 최종검증일
- 지급방식, 연간 횟수, 동일질병 재지급, 동일일 복수치료·수술, 지급기간, 한도, 병원급 조건, 면책·감액, 제외조건

특히 암 주요치료비는 담보 하나로 합치지 않고 `수술`, `항암약물`, `항암방사선`, `기타 치료`별 지급 규칙을 별도로 저장합니다. 뇌·심장 치료비는 질병별/치료별/통합 지급 기준을 별도로 기록합니다.

### 특약명 정규화 원칙

보험사별 특약명은 비교의 기준이 아닙니다. 앱의 정규화 사전은 특약명으로 **후보 보장 기능**을 찾고, 다음 항목이 약관 원문으로 검증된 경우에만 해당 기능에 확정 연결합니다.

1. 지급사유와 대상 질병·치료 정의
2. 지급단위(질병별·치료별·통합), 반복·연간 한도
3. 병원급 조건, 면책·감액, 주요 제외조건
4. 약관 조항·페이지·기준일

보험사 목록은 데이터 입력 대상 카탈로그일 뿐, 모든 회사의 모든 상품이 검증됐다는 뜻이 아닙니다. 실제 비교 결과에는 `검증 완료` 상태인 담보만 노출해야 합니다.

향후 운영 시에는 코드 내 샘플 데이터를 JSON 또는 데이터베이스로 옮기고, 약관 원문 파일과 조항·페이지 근거를 연결하는 것을 권장합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. Source에서 **Deploy from a branch**, Branch에서 `main`과 `/ (root)`를 선택해 저장합니다.
4. 표시되는 `https://사용자이름.github.io/저장소이름/` 주소로 접속합니다.

정적 파일만 사용하므로 GitHub Pages에서 바로 동작합니다. PDF 업로드 기능은 현재 개인정보를 저장·분석하지 않는 UI 자리이며, 실제 분석 기능을 붙일 때는 서버 처리, 동의 절차, 보관·삭제 정책을 별도로 설계해야 합니다.
